# Amazon India Sales Analysis Dashboard 📊

## Project Overview

This project is an **Amazon India Sales Analysis Dashboard** created using Microsoft Excel. The objective is to analyze sales performance, profitability, products, orders, payment methods, fulfillment methods, and geographic performance through an interactive management dashboard.

## Key Features

- Total Sales, Profit, Orders & Units Sold
- Average Order Value and Profit Margin
- Monthly Sales & Profit Trends
- Category-wise Sales, Profit & Units Sold
- Top 10 Products by Sales
- Order Status Analysis
- Return Rate & Cancellation Rate
- Category-wise Returns & Cancellations
- Sales & Profit by Payment Method
- Sales & Profit by Fulfillment Method
- State-wise Sales, Profit & Orders
- Business Insights for management decision-making

## Tools & Techniques

- Microsoft Excel
- Data Cleaning & Preparation
- Excel Formulas
- PivotTables
- PivotCharts
- KPI Analysis
- Dashboard Design
- Business Insights

## Dashboard

The final dashboard provides a consolidated view of Amazon India sales performance and helps identify key trends and business performance across products, categories, payment methods, fulfillment methods, order status, and states.

## Project Outcome

The project demonstrates how raw sales data can be transformed into meaningful **KPIs, visualizations, and business insights** to support data-driven decision-making.

## Dataset

The analysis is based on an Amazon India sales dataset containing order, product, sales, profit, payment, fulfillment, order-status, and state-level information.
